# HandwerkPilot – ElektroFix Achern

Static portfolio demo exported from the complete WordPress implementation.

The public version includes all seven pages, the latest homepage card artwork,
responsive navigation, the price calculator and the multi-step request form.
The public form is demo-only and never stores or sends submitted data.

The original WordPress version uses a custom theme and a separate plugin with a
private service-request post type, validation, image upload, status management,
admin notes and CSV export.
