Bäckerei Website

Produktkatalog, Filialen und Vorbestellung für eine fiktive Bäckerei — mit strukturierten Inhalten in WordPress.

Statische VorschauGitHub-Repository

Die öffentliche Vorschau ist ein statischer Export: keine echte Bestellung oder Zahlung. Die überarbeiteten Dateien liegen im gelieferten Projektpaket; GitHub kann noch den vorherigen Stand zeigen.

Aufgabe, Zielgruppe und Rolle

Besucher sollen Produkte und Filialen finden und eine Vorbestellung vorbereiten können; Inhalte sollen im Admin pflegbar sein. Eigenes Praxisprojekt, kein Kundenauftrag.

Funktionen und Architektur

  • Produkt- und Filialseiten mit strukturierten Daten, Suche und Filtern.
  • JavaScript unterstützt die Produktauswahl; PHP validiert die Anfrage im WordPress-Projekt.
  • Vorbestellungen werden im Admin mit Status bearbeitet.
Theme / Templates → Core-Plugin / Hooks → WordPress-API → Inhalte und Metadaten (wp_posts / wp_postmeta), Einstellungen in Optionen

Entscheidungen

  1. Theme und Plugin trennen: Ein Layoutwechsel soll Inhaltsmodell und Verarbeitung nicht entfernen.
  2. Strukturierte Inhalte: Produkte und Filialen werden im Admin verwaltet und in Templates dargestellt.
  3. Korrekturen erlauben: Eine ungültige Eingabe löst keine Sperrfrist aus; die Auswahl bleibt beim Fehler erhalten.
  4. CSV sicherer ausgeben: Formelauslösende Zeichen am Anfang werden neutralisiert.

Prüfung und Grenzen

Die bestehende Regressionstest-Suite nutzt API-Doubles; zusätzlich wurde der Ablauf in lokalem WordPress mit Testdaten geprüft. Diese Tests sind kein vollständiger End-to-End-Nachweis. Weitere Einzelheiten stehen im QA-Bericht.

Keine reale Bäckerei, keine produktive Bestellung. Im lokalen Testdatensatz können Produktbilder identisch sein; die Abholzeit wird noch nicht gegen Filialöffnungszeiten geprüft.
